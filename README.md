# Teo Studio

<img src="assets/icon.png" width="120" alt="Teo Studio 茶杯与 AI 星芒图标" />

一个以任务为核心的个人 AI 工作台。Teo 取意 Tea：让工作有着落，也让协作轻松一点。

## 产品方向

- **统一任务入口**：快速输入、表单创建，或由 AI 扫描邮件、Jira 等渠道提出候选任务。
- **来源为准**：平台管理索引；任务内容以 Jira、GitHub 等来源为准。无外部来源时使用 Markdown 文件。
- **人与 AI 协作**：按 Skill、Connection 和上下文处理任务；遇到问题暂停，人工回答或审核后继续。
- **主动关注**：发现新任务，检查进展并提醒需要推进的事项。默认检查间隔 10 分钟，可配置。
- **双引擎**：首期支持 Codex 和 Claude；每次执行选择一个引擎。
- **自己的 MCP**：外部 AI 可通过工作台 MCP 创建、查询和操作任务，与界面共用业务规则。

## 技术方向

Python 后端 · SQLite 平台数据 · 可安装 PWA · Codex / Claude 引擎适配

Windows 和 macOS 可通过 Chrome 安装后，以独立应用窗口打开。本期不实现登录；服务面向本机或受信网络，不应直接公开部署。

## 协作

从最新 `main` 创建功能分支，开发后通过 Pull Request 合并。Fork 开发前先同步上游；说明 PR 的改动、验证结果和未验证条件。

不要提交 API Key、访问令牌、`.env`、SQLite 运行数据、真实邮件、公司私有资料或本机 AI 会话文件。代码仓库与实际任务工作目录分开管理。
